# 🍽️ Restaurant Chatbot

A simple Restaurant Chatbot built with **Python** and **Pandas**.  
This project simulates a restaurant ordering system where users can browse the menu, search for items, and interact with the chatbot through the terminal.

---

## 🚀 Features

- 📋 Display the restaurant menu
- 🔍 Search food by **ID**
- 🔍 Search food by **Name**
- ✅ Input validation
  - Prevents empty input
  - Prevents invalid IDs
- 💬 Friendly chatbot responses
- 📦 Reads menu data from a CSV file using Pandas
- 🖥️ Clean terminal interface

---

## 🛠️ Technologies Used

- Python 3
- Pandas
- CSV

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/YourUsername/Restaurant-Chatbot.git
```

Go to the project folder:

```bash
cd Restaurant-Chatbot
```

Install dependencies:

```bash
pip install pandas
```

Run the project:

```bash
python chatbot.py
```
